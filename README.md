If not running, replace the debug.keystore found in C:\Users\YourName\.android into the root folder.
If still not running, update JDK and JRE versions to recent, as well as maven and gradle in your Program Files
Go to environmental variables
in system variables
  add JAVA_HOME with directory to the java version (i.e. C:\Program Files\Java\jdk-21) 
  add MAVEN_HOME with directory to the maven version (i.e. C:\Program Files\apache-maven-3.9.6)
in user variables, add to Path, press New
  add the directory to the bin folder of java and maven (i.e. C:\Program Files\Java\jdk-21\bin or C:\Program Files\apache-maven-3.9.6\bin)
